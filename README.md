# Дима Сторыч — Интернет-магазин

Полноценный интернет-магазин с оплатой через **ЮKassa**.

## 🚀 Быстрый старт

```bash
npm install
cp .env.example .env   # заполните SHOP_ID и SECRET_KEY от ЮKassa
npm start
```

Откройте http://localhost:3000

## 📦 Функционал

- Каталог товаров с категориями
- Корзина (сессии)
- Оформление заказа
- Оплата через ЮKassa (банковские карты, СБП, ЮMoney)
- Админ-панель (управление товарами и заказами)
- История заказов

## ⚙️ Переменные окружения (.env)

| Переменная | Описание |
|---|---|
| `SHOP_ID` | ID магазина из ЮKassa |
| `SECRET_KEY` | Секретный ключ ЮKassa |
| `ADMIN_PASSWORD` | Пароль для входа в админку |
| `SESSION_SECRET` | Секрет для сессий |
| `PORT` | Порт (по умолчанию 3000) |

## 🛠 Технологии

- Node.js + Express
- EJS (шаблоны)
- SQLite (база данных)
- ЮKassa API (платежи)
